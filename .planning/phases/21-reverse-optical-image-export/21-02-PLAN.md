Close RIMG-02: re-emit the optical `<sampleList>/<sample>` on the reverse path. Two pieces:
(1) a true INVERSE of the Phase-20 forward fold — `recover_descriptive(&ImageEntry)` that splits the
folded `modality`/`derived_subtype` free-text back into structured IMS descriptive attributes,
reusing ONE shared set of named IMS accession/name constants (introduced in `optical.rs`) so the
forward PARSE and reverse EMIT can never drift; and (2) the `<sampleList>/<sample>` emission in
`ImzmlWriter` carrying `IMS:1006008` (value = the Plan-01 exported filename) + those recovered
cvParams, wired into `convert`/`run_pipeline` by calling Plan 01's `export_image_members` and
threading the result into `write_header_to`.

Purpose: This is the descriptive symmetry half of the reverse optical restore (addresses v0.5
MAJOR-8). The anti-drift constant sharing is load-bearing: the fold is only invertible if both
directions agree on the exact accession/name strings.

Output: a reverse `.imzML` that, for an archive with embedded optical images, carries a `<sample>`
with `IMS:1006008` → exported file + recovered `IMS:1006015/1006017/1006011/1006012/1006013`; and an
archive with no images emits no optical `<sampleList>` (no-op preserved — RIMG-03's no-op surface).
</objective>

<interfaces>
The forward fold to invert (src/write/convert.rs:620-658) — its inverse contract:
```
// FORWARD (map_descriptive): OpticalImageRef -> ImageEntry
//   modality       = join("; ", [staining_method?, format!("aligned: {alignment_method}")?])
//   derived_subtype= match (subject, morphology):
//        (Some(s), Some(m)) => "{s}: {m}"   // s ∈ {"of-analysed-sample","adjacent-section"}
//        (Some(s), None)    => "{s}"
//        (None,    Some(m)) => "{m}"
//        (None,    None)    => None
// INVERSE (recover_descriptive): ImageEntry -> RecoveredOptical
//   split modality on "; "; a part with prefix "aligned: " -> alignment_method (strip prefix),
//        any other non-empty part -> staining_method
//   derived_subtype: if it starts with "of-analysed-sample"/"adjacent-section" set that subject
//        bool; the remainder after a leading "<subject>: " is morphology; a value matching no
//        subject prefix is morphology alone.
```
Named constants to introduce in src/schema/optical.rs (values from the CV doc, verbatim):

```
IMS:1006008 "optical image location"
IMS:1006011 "optical image of analysed sample"
IMS:1006012 "optical image of adjacent section of analysed sample"
IMS:1006013 "sample morphological classification"
IMS:1006015 "staining method used for optical image"
IMS:1006017 "method used to align optical image"
```
