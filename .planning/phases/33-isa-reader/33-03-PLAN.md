<objective>
Wire the two ISA readers (Plans 33-01 ISA-Tab, 33-02 ISA-JSON) into the converter: a `--isa <PATH>`
CLI flag threaded through `convert_mzml`, a new ISA arm at the existing `finish_parquet → zip` seam
that (1) parses the bundle into the shared `SampleMetadataDoc`, (2) embeds the WHOLE ISA bundle
byte-for-byte as typed `sample-metadata`/`isa` member(s) under a stable `sample_metadata/isa/` prefix
with `data_kind = "isa"` (the Phase-30 `ISA_DATA_KIND` carve-out token), and (3) REUSES the Phase-32
projection (`project_sample_list` / `build_run_sample_binding` / `match_rows_for_data_file`) +
`study_metadata` back-ref. The model + embed helper + projection are all reused; the NEW code is the
CLI flag, the dispatch sniff/path, the multi-file embed loop, and the ISA-bundle sibling-locator.

This is the ONLY plan in Phase 33 that touches `src/cli.rs` and `src/write/mzml.rs`. Keep the `--isa`
arm strictly additive: the no-flag path must stay byte-identical (the `--sdrf` arm and the plain
convert path are untouched).

Purpose: deliver SM-10 — a native MetaboLights ISA bundle ingests, embeds losslessly, and roundtrips.
Output: `--isa` flag + ISA emit seam + bundle-locator helpers + the MTBLS5358 acceptance test.
</objective>
