<objective>
Implement Phase 35's reporter-ion quantitation (QUANT-01..02): with `--reporter-quant`, extract per-MS2
reporter-ion intensities (lean scope: at the Phase-34 channel reporter m/z from each MS2 spectrum, or
pass-through when the source already carries a reporter-ion array) and store them keyed by `channel_id`
to the labeled `sample_list` channel entries, using the carrier the 35-01 decision gate selected
(aux-array OR documented sidecar map). Prove the round-trip recovers intensities + `channel_id` through
THIS repo's own reader, keep the no-flag path byte-identical, and complete the three-places rule.

Purpose: deliver the demoable reporter-quant vertical (breadth, not the core sample↔file value — this is
the first-to-cut facet, kept lean). The converter STORES reporter intensities; it never computes or
deconvolves them (design R8 / out-of-scope).
Output: extraction + emit wiring behind `--reporter-quant`, an own-reader round-trip XRT test, the
`schema/reporter_quant.json`, and the spec write-up entry.
</objective>
