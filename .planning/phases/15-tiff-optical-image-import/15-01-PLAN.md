<objective>
Extend `ImageEntry` and the in-repo `schema/imaging.json` with three OPTIONAL image-classification fields — `role`, `derived_subtype`, `modality` — so the TIFF importer (Plan 03) can stamp `role="optical"` on each imported image and the emitted index validates. This restores doc↔schema↔struct consistency with the committed V2 spec snippet (IMG-05).

Purpose: The committed V2 spec doc already documents `role`/`derived_subtype`/`modality` on `images[]`, but the in-repo `schema/imaging.json` and the `ImageEntry` struct do NOT yet carry them. The importer must set `role="optical"`; without these fields the `images_item_matches_schema` / `round_trips_full_shape` schema-consistency tests would reject the new keys (the schema is `additionalProperties:false`). This plan lands the foundation Plan 02/03 build on.

Output: `ImageEntry` gains three optional fields; `schema/imaging.json` gains the matching optional properties; the spec doc gets a short in-repo-consistency note; all schema/metadata tests stay green and are extended to cover the three fields.
</objective>
