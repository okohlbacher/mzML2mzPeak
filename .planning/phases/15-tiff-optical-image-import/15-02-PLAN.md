<interfaces>
Affine formula (CONTEXT-LOCKED, RESEARCH §Affine / Code Examples):
- `fn full_extent_affine(nx: i64, ny: i64, w: u32, h: u32) -> [f64; 6]`
- `a = if w > 1 { (nx-1) as f64 / (w-1) as f64 } else { 0.0 }`
- `e = if h > 1 { (ny-1) as f64 / (h-1) as f64 } else { 0.0 }`
- return `[a, 0.0, 1.0, 0.0, e, 1.0]`  // [a,b,c,d,e,f]; (x_ms,y_ms) = (a*col + c, e*row + f)
- Corner check: (col=0,row=0) → (1,1); (col=W-1,row=H-1) → (Nx,Ny).

tiff API (RESEARCH Q2 / Pattern 3, docs.rs/tiff/0.11.3):
- `tiff::decoder::Decoder::new(r) where r: Read + Seek -> TiffResult<Decoder<R>>`
- `Decoder::dimensions(&mut self) -> TiffResult<(u32, u32)>` (reads first IFD, NO pixel decode)
- Errors are `tiff::TiffError`; map to the new typed WriteError variant.

sha2 streamed (RESEARCH Pattern 4):
- `sha2::Sha256` + `sha2::digest::Digest`; 64 KiB chunk loop; accumulate `size += n` while hashing; finalize → lowercase hex.
</interfaces>
