<objective>
Create the own verbatim-string `SourceCurie` type in `src/schema/` — the single place the
cvParam-or-userParam decision is shaped (Cornerstone A, SMCVG-01). This is the keystone CV type the
whole v0.8 sample-metadata stream depends on: every SDRF `AC=` token and every ISA `Term Accession
Number` becomes a `SourceCurie` that the emitter (Phase 31+) turns into a cvParam, OR — when no
accession exists — degrades to a userParam keyed by the exact source column. The type validates SHAPE,
not existence; it adds ZERO new ontology dependencies.

Purpose: `mzdata::CURIE` is a CLOSED-CV integer-accession enum that silently collapses
NCBITaxon/Unimod/Cellosaurus/CHMO/MSIO to `Unknown`, breaking the reversibility invariant (design
review finding R3-H1). v0.8 must preserve those prefixes verbatim, so we own a string-based type
instead of reusing `mzdata::CURIE`.

Output: `src/schema/source_curie.rs` with `pub struct SourceCurie { prefix: String, accession: String,
label: Option<String> }`, a shape-validating parser, serde derives, and a full shape-round-trip test
module.

This plan is FOUNDATION ONLY — it defines the type and proves its shape behavior. No facet emits here;
the emitter that consumes `SourceCurie` lands in Phase 31 (SM-01).
</objective>

<feature>
  <name>SourceCurie verbatim-string passthrough type with shape-only validation</name>
  <files>src/schema/source_curie.rs</files>
  <behavior>
    Shape parsing (`SourceCurie::parse(&str) -> Result<SourceCurie, ParseError>`):
    - Test 1: `parse("MS:1002791")` → Ok with prefix="MS", accession="1002791", label=None.
    - Test 2: `parse("NCBITaxon:9606")` → Ok, prefix="NCBITaxon" preserved verbatim (NOT collapsed
      to Unknown — the exact failure mode mzdata::CURIE has).
    - Test 3: `parse("UNIMOD:35")` → Ok, prefix="UNIMOD" preserved verbatim.
    - Test 4: `parse("CHMO:0000470")` and `parse("MSIO:0000055")` → Ok, exotic prefixes preserved.
    - Test 5: a free-text value with no colon, e.g. `parse("homo sapiens")` → Err (no `prefix:accession`
      shape) — this is the signal the caller uses to emit a userParam instead of a cvParam.
    - Test 6: shape-only, NOT existence: `parse("MS:9999999")` (a non-existent accession) → Ok. We do
      NOT fetch the ontology; a well-formed-but-unknown accession is still a valid SourceCurie.
    - Test 7: edge shapes — empty prefix (`":1234"`) → Err; empty accession (`"MS:"`) → Err; multiple
      colons (`"PRIDE:PRIDE:0000")` — decide and pin: split on FIRST colon so accession may contain
      a colon verbatim, prefix="PRIDE", accession="PRIDE:0000" (record the rule in a doc comment).
    Verbatim round-trip:
    - Test 8: for every accepted input above, `parse(s).unwrap().to_curie_string()` (Display /
      `prefix:accession`) re-serves the prefix+accession byte-identical to the input.
    - Test 9: serde serialize→deserialize of a `SourceCurie { prefix, accession, label: Some(..) }`
      round-trips equal; `label: None` is OMITTED from the JSON (skip_serializing_if).
    - Test 10: `deny_unknown_fields` rejects a JSON object carrying an undeclared key.
  </behavior>
  <implementation>
