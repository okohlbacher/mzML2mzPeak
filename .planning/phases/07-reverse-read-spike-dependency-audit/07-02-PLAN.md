`mzpeak_prototyping::MzPeakReader` surfaces everything the reverse path will consume:
spectrum count, per-pixel source-dtype m/z+intensity arrays (no widening), per-pixel IMS

non-imaging archive hard-fails with a typed error. Delivers RMZ-01, RMZ-02, RMZ-03, RMZ-04.

`src/reverse/source.rs`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.mzpeak` archive -> MzPeakReader | The archive is untrusted input; every read must be bounds-checked and fallible-safe (no `unwrap`). |
| array dtype on a decoded DataArray | A forged dtype outside {Float32,Float64} must be rejected, not cast. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | non-imaging / wrong-CV archive treated as imaging | mitigate | Read helper + spike return `ReverseError::NotImaging` when the first spectrum lacks IMS:1000050/51 (fail-closed before any downstream use); proven by `non_imaging_fails_closed`. |
| T-07-02 | Tampering | array dtype outside {Float32,Float64} silently coerced | mitigate | `dtype()` branch rejects other dtypes with `ReverseError::UnsupportedDtype`; coercing `mzs()`/`intensities()` accessors forbidden (grep-gated in acceptance). |
| T-07-03 | Denial of Service | OOB index / panic via unwrap on a malformed archive | mitigate | Iterate `0..len()` only; every `get_spectrum_*` returns `Option`/`io::Result` surfaced as a typed `ReverseError`, never `unwrap` (mirrors verify.rs:31). |
| T-07-04 | Denial of Service | unbounded memory on the 34,840-pixel real archive | mitigate | Read one index at a time (bounded head-sample in the spike, single-index helper in tests); never collect a `Vec` of all spectra. `load_all_spectrum_metadata()` primed once avoids the O(n^2) rescan hang. |
</threat_model>
