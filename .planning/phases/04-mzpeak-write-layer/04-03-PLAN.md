<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ImagingReader stream → archive | Spectra produced one-at-a-time; bounded memory. No external network input. |
| produced .mzpeak → MzPeakReader (round-trip) | The archive is re-opened in-process by the reference reader for verification only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Denial of Service | Unbounded memory from buffering all spectra | mitigate | Streaming one-at-a-time loop; `collect`/`Vec<ImagingSpectrum>` grep-gated to 0 in convert.rs (IN-08, CONTEXT Area 1). |
| T-04-07 | Denial of Service | Panic on malformed/empty fixture spectrum (zero-length arrays, ms_level==0) | mitigate | convert propagates `WriteError` via `?` with no `unwrap` on writer/reader results; fixture exercises an edge pixel; arrays carried verbatim. |
| T-04-zip | Tampering | Zip-slip on archive entry names | accept | Archive entry names are produced internally by `ZipArchiveWriter` (`build`/`finish`) from fixed constants, not from untrusted input; out_path is a single caller file (`File::create`). No attacker-controlled entry name path exists. |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages; pinned `=` + committed Cargo.lock + vendored mzdata. |
</threat_model>
