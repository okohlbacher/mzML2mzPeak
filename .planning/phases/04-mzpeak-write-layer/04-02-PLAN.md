| in-process metadata → archive footer | Source metadata + provenance already typed by the read layer; serialized into the archive by the writer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Information disclosure / interop break | Accidental AES-encrypted output | mitigate | Never call `.encryption_properties(...)`/`.encrypt_parquet(...)`; leave default empty (V6). Grep gate in Task 1 asserts zero occurrences. |
| T-04-04 | Tampering | Path handling on caller-supplied output path | mitigate | Use `File::create` on the `&Path` as-is; do not interpret/join path contents (V12). The archive entry names are produced internally by `ZipArchiveWriter` (`build`), not from untrusted input, so zip-slip on entry names is not reachable here. |

| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages; pinned `=` + committed Cargo.lock + vendored mzdata. Cargo.toml must remain unchanged (asserted in Task 2 acceptance). |
