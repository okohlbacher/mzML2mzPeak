<objective>
Deliver VAL-01 — the HARD release gate for the whole v0.8 sample-metadata milestone: an internal,
pure-Rust roundtrip-parity assertion that, for every sample-metadata fixture, converts the fixture
WITH its SDRF/ISA, then re-serves the embedded verbatim member and asserts it is BYTE-FOR-BYTE
identical to the source — and that the projected `sample_list`/`study` (and the ISA whole-bundle
member) read back. This is ALWAYS the gate; it shells to nothing.

Purpose: lock the lossless-anchor invariant (the verbatim blob is the only roundtrip source — Q10
RATIFIED) across the breadth of fixtures the milestone targets, so a future regression that silently
corrupts an embedded member fails the build. The byte-`assert_eq!` is the cheap XRT roundtrip
assertion this phase owes (vs. imaging's numeric comparator). Also ship the user-facing reverse
extract: `--reconstruct-sdrf` / `--reconstruct-isa` re-serve the embedded bytes (NOT a regeneration).

Output: a library `extract_sample_metadata_member()` member-extract helper (`src/sdrf/embed.rs`),
the `--reconstruct-sdrf`/`--reconstruct-isa` CLI reverse path (`src/cli.rs`), and the VAL-01
fixture-sweep acceptance test (`tests/sample_metadata_roundtrip.rs`).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| produced .mzpeak ZIP → reader/extract | a member could be absent, renamed, or corrupted vs. what was embedded |
| CLI argv → reconstruct mode | user supplies an archive path + output path; modes must not silently mix |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01 | Tampering | embedded member silently differs from source | mitigate | VAL-01 byte-`assert_eq!` re-serve on every present fixture; PRESENT fixture failing the assertion fails the build (no length/hash-only weakening) |
| T-37-02 | Information disclosure | reconstruct writes to a path that overwrites the input archive | mitigate | reuse the existing reject_output_collision/self-overwrite guard pattern before writing the extracted bytes |
| T-37-03 | Denial of service | reconstruct on a malformed/huge ZIP | accept | bounded by zip 4.x member reads; extract is read-only, no spectrum decode |
| T-37-EXIT | Repudiation | reconstruct failure maps to an undocumented exit code | mitigate | route through the existing 5-code classify_exit; add NO new code (T-10-EXIT) |
| T-37-SC | Tampering | npm/pip/cargo installs | mitigate | no new dependency added (zip/serde_json already pinned); nothing to install — slopcheck N/A |
</threat_model>
