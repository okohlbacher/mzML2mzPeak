<objective>
Declare a file-level `cv_list` in the forward mzPeak archive enumerating every controlled
vocabulary it references — MS (PSI-MS), IMS (imaging MS), and UO (Unit Ontology) — per spec
Edit 2 (CVL-01). Add the governing `schema/cv_list.json`, a `CvEntry` struct, and a single
shared CV-identity constant that both the forward `cv_list` and the existing reverse imzML
`<cvList>` draw from so the two directions can never disagree. Update the spec doc's CV List
subsection to match.

Purpose: mzPeak's column-name inflection and `parameters` reference CV codes (MS/IMS/UO); the
archive must declare those CVs once at file level, analogous to mzML's `<cvList>`, so a reader
can resolve every accession to a declared, versioned ontology URI.

Output: `schema/cv_list.json`, `src/schema/cv.rs` (CvEntry + shared constant), the `cv_list`
emission wired into `convert.rs` via `add_index_metadata`, and a refreshed spec-doc CV List
subsection — the "three places" delivery for CVL-01.
</objective>
