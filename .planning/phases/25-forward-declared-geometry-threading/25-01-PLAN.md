<objective>
Close the GEOF-01 consistency-guard gap in the forward declared-geometry path. The forward path ALREADY
threads the parsed `<scanSettings>` geometry through `convert_with(.., Some(&geom))`, ALREADY derives
`metadata.imaging` geometry from it, and ALREADY flips `pixel_count_source` to `"declared"` when a declared
grid is present (Phase 18/19). What is MISSING — and is the only behavioral change GEOF-01 actually needs —
is the locked CONTEXT edge rule: **if the declared grid is INCONSISTENT with the observed coordinates
(observed pixel extent exceeds the declared grid), do NOT trust the declared count — keep
`pixel_count_source = observed_max`, do NOT fabricate, and emit a counted warning.** Today
`IndexAccumulator::fold_into` trusts the declared grid unconditionally.

Purpose: honor the source's declared grid when it is authoritative, but never let a wrong/partial declared
grid silently overwrite the truth the pixels themselves prove. This is the "do NOT fabricate" half of the
GEOF-01 decision.
Output: a consistency-guarded `fold_into`, a counted inconsistency signal surfaced as a non-fatal warning on
both the library convert path and the CLI. No new deps; pinned stack unchanged.
</objective>

// IndexAccumulator holds: x_max, y_max, z_max: Option<i64>, seen_any: bool, mz_min/mz_max: Option<f64>
pub fn fold_into(&self, block: &mut ImagingMetadata) {
    if block.pixel_count.is_some() {
        block.pixel_count_source = Some(PixelCountSource::Declared);   // <-- UNCONDITIONAL trust (the bug)
    } else if self.seen_any {
        block.pixel_count = Some(PixelCount { x: self.x_max, y: self.y_max, z: self.z_max });
        block.pixel_count_source = Some(PixelCountSource::ObservedMax);
    }
    if let (Some(min), Some(max)) = (self.mz_min, self.mz_max) {
        block.mz_range = Some(MzRange { min, max });
    }
}
