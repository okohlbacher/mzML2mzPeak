- `pub imzml_metadata: ImzMLFileMetadata` field on the reader (line 528).

`ImzMLFileMetadata` struct (lines 53-59):
  - `pub uuid: Option<Uuid>`
  - `pub data_mode: Option<IbdDataMode>`
  - `pub ibd_checksum: Option<String>`
  - `pub ibd_checksum_type: Option<String>`   // "MD5" | "SHA1" | "SHA256"
  - `pub ibd_file_name: Option<String>`

`pub enum IbdDataMode { Processed, Continuous }` (line 43).

Per-spectrum coordinate access (from ARCHITECTURE.md, verified in vendor tests.rs):
  - `spec.acquisition().scans[0].get_param_by_curie(&curie!(IMS:1000050))` -> position x
  - `&curie!(IMS:1000051)` -> position y ; `&curie!(IMS:1000052)` -> position z (optional)
  - The returned `Param` value -> integer via `.value.to_i64()` (handle the Result/Option).
  - m/z point count: `spec.raw_arrays()?.mzs()?.len()` (standard mzdata `BinaryArrayMap`).
  - `curie!` macro and `get_param_by_curie` come from mzdata's params module (re-exported through the prelude).
