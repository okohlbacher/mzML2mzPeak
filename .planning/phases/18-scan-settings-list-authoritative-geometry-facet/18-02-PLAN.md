<objective>
Make `scan_settings_list` the authoritative geometry facet in the forward path and the
`metadata.imaging` geometry block its DERIVED copy (GEO-02 — the crux). Thread the parsed
`ImagingRunMetadata` into the forward convert path, build the facet via Plan 18-01's
`scan_settings_list_from_geometry`, emit it through `add_index_metadata("scan_settings_list", ..)`
alongside `cv_list` + `imaging` before `finish()`, and pass the SAME `ImagingRunMetadata` into
`write_run_metadata` so `assemble_imaging_metadata` regenerates the imaging-block geometry from
one source. Preserve the `pixel_count_source` declared|observed_max distinction and the
no-fabrication rule.

Purpose: single source of truth for run-constant geometry; the index geometry can no longer
drift from the authoritative facet because both derive from the same parsed struct.
Output: emitted `scan_settings_list` block + imaging-block geometry derived from the same source.
</objective>
