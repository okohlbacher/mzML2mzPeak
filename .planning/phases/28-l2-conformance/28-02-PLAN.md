      lossless/L1 regardless — so for imaging, L1 remains correct and L2 is a no-op-equivalent superset
      (do NOT change the imaging lossless guarantee). Resolve the level as: explicit `l2` ⇒ L2; else
      L1 (drop the implicit `enc.lossy_mz ⇒ L2` auto-pick in favor of the explicit flag, keeping the
      existing log line that explains numpress+L1 mismatch / suggests `--no-numpress` or
      `--conformance l2`).
    - `run_forward_mzml` (plain mzML, ~226): the `--verify` arm currently does a structural read-back
      count only (no numeric compare). Thread the selected `ConformanceLevel` so the log line + exit
