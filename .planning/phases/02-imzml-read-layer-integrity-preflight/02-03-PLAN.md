<objective>
Build the production streaming read layer: an `ImagingReader` that opens an .imzML/.ibd
pair (running the Plan 02-02 integrity preflight FIRST and refusing to proceed on
failure), auto-detects the storage mode from the file-level data_mode CV param, and
yields one fully-populated `ImagingSpectrum` at a time via the `Iterator` trait — never
collecting all spectra, so the 34,840-spectrum / 815MB dataset streams under bounded
memory. This is the layer Phase 4's writer consumes.

Purpose: turn the proven spike read path (spike_coords.rs) into a reusable library API
that delivers per-pixel coordinates (SPA-01), decoded m/z+intensity arrays (IN-04),
storage-mode detection (IN-03), and carried per-spectrum metadata (IN-06), for both
processed (IN-01) and continuous (IN-02) modes, bounded in memory (IN-08).

Output: `src/read/stream.rs` with `ImagingReader`, the `pub mod stream;` wiring in
`src/read/mod.rs`, and integration tests over the committed continuous fixture plus the
gitignored-.ibd processed file (guarded to skip when absent).
</objective>

  coordinate must surface as an Err for that pixel, never a silent default.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .imzML/.ibd → ImagingReader | Untrusted external file: declared array lengths/offsets and coordinate params cross into the streaming reader |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering | bad .ibd reaches the stream | mitigate | ImagingReader::open calls preflight() FIRST and returns Err without constructing the reader (key_link enforced; preflight_blocks_streaming test asserts it) |
| T-02-07 | Denial of Service | 815MB .ibd / 34,840 spectra materialized in memory | mitigate | streaming Iterator yields one ImagingSpectrum at a time; no collect-all in lib or tests (grep gate + counting test) — IN-08 |
| T-02-08 | Tampering | silent zero-length / defaulted arrays masking a decode failure | mitigate | None raw_arrays or Err mzs/intensities is a hard ReadError, never a zero-length substitute (PITFALLS 9/10) |
| T-02-09 | Information disclosure | out-of-range external offset/length from a malformed imzML | accept | mzdata's reader.rs performs the seek+read_exact and surfaces an Err on out-of-range, which maps to ReadError::Decode; bounds-hardening of mzdata internals is out of this phase's scope (documented residual, deferred to a hardening pass) |
</threat_model>
