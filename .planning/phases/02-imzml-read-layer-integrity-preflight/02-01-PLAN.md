<objective>
Establish the Phase 2 library crate and define the data contracts that the rest of the
read layer (Plan 03 streaming reader) and Phase 4's writer will consume. This is the
interface-first skeleton plan: it creates `src/lib.rs`, wires the `[lib]` target in
`Cargo.toml`, declares the `read` and `integrity` module seams, and defines the
per-spectrum record type and run-level provenance type that downstream plans implement
against.

Purpose: downstream plans (integrity preflight, streaming reader, future writer) must
build against fixed type contracts rather than rediscovering field shapes. Defining the
record type and run provenance first prevents a scavenger hunt and locks the coordinate
semantics (SPA-02) and carried metadata (IN-05 representation flag, IN-06 ms_level + id)
in one place.

Output: a compiling library crate with `ImagingSpectrum`, `RunProvenance`,
`Representation`, and `StorageMode` types, the `read` module surface, and an `integrity`
module declaration that Plan 01-equivalent code fills.
</objective>
