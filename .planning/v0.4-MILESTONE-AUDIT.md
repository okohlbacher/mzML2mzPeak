## Cross-Phase Integration (5/5 WIRED)

1. **P8 `ArrayRef` triple → P9 external-data CV refs** — `IMS:1000102/103/104` with
   `IMS:1000103` = ELEMENT count (not bytes); producer/consumer agree by construction.
2. **Single minted UUID** threaded P8↔P9↔P10 — `.ibd` 16-byte header UUID == `.imzML`
   `IMS:1000080` (one `Uuid::new_v4()` in `convert.rs`).
3. **P8 `finish()` MD5 → P9 `IMS:1000090`** via the Option-C body-temp-file ordering;
   identical shared `compute_digest` on both write and forward-preflight sides.
4. **P10 `convert()`** chains P7 read → P8 append → P9 emit in one bounded loop (one pixel
   live, no collect; `load_all_spectrum_metadata()` primed once).
5. **P11 roundtrip** feeds the reverse output to the UNMODIFIED v0.3 forward
   `ImagingReader::open` + `convert()`; integrity preflight passes by construction. The three
   Phase-11 production fixes (single-line `<fileContent>` accession-scoped parse; `ms level`
   + MS1/MSn type term; profile/centroid continuity) are coherent and required, not hacks.
