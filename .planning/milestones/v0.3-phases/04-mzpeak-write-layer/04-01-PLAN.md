<objective>
Stand up the `src/write/` module and implement the core, genuinely-new mechanism of Phase 4:
reconstructing an mzdata `MultiLayerSpectrum` from an `ImagingSpectrum`. This is the
impedance match that makes coordinate columns serialize as real values (not all-NULL) and
makes profile/centroid routing automatic.

Purpose: The reference writer (`mzpeak_prototyping`) consumes `SpectrumLike`, not our
`ImagingSpectrum` record type, and it reads coordinate values from scan-event CV params at
write-time (RESEARCH.md Pitfall 1). This plan produces the reconstruction that re-attaches
`IMS:1000050/51/52` params and re-encodes the m/z + intensity arrays at their source dtype.

Output: `src/write/mod.rs`, `src/write/spectrum.rs` (with `to_mzdata` + inline unit tests),
and a one-line additive edit to `src/lib.rs`.
</objective>
