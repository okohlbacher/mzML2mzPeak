<objective>
Implement `ImagingWriter`: the struct that wraps the upstream `MzPeakWriterType<File>`, does
the one-time coordinate-column registration through the public extension seam (OUT-02), maps
source + provenance into the archive's file_description, and ASSEMBLES + EXPOSES the imaging
metadata block for the finish stage (OUT-03). It also defines the typed `WriteError`.

Purpose: OUT-02 requires coordinate columns registered SOLELY via `add_spectrum_scan_field` /
`CustomBuilderFromParameter::from_spec` with zero core-struct edits; OUT-03 requires PSI-MS +
IMS metadata plus the Phase-3 `metadata.imaging` block to land in the archive. This plan owns
the writer wrapper, the source/provenance metadata wiring, and assembling/exposing the
`metadata.imaging` block. The ACTUAL insertion of that block into the archive index happens at
the terminal finish sequence (`finish_parquet()` → `add_index_metadata("imaging", &block)` →
`finish()`), which is owned by Plan 03's convert orchestrator (RESEARCH.md Q4, RESOLVED). The
read→write drive loop and round-trip proof are Plan 03.

Output: `src/write/writer.rs` with `ImagingWriter`, its `new`/`write_spectrum`/`finish_parquet`
surface, the metadata mapping, the imaging-block accessor, and `WriteError`.
</objective>
