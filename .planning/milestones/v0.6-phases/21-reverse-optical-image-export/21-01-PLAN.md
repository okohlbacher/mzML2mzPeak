<objective>
Build the reverse image-member EXPORT primitive (RIMG-01): given the `.mzpeak` archive path and
the `metadata.imaging.images[]` entries already loaded by the reverse `convert`, read each embedded
optical-image ZIP member's bytes back out and write them as external image files beside the produced
`.imzML`. This is a self-contained new module (`src/reverse/image_export.rs`) — NO wiring into the
`convert` orchestrator yet (Plan 02 does that), so this plan owns no shared file beyond `mod.rs`.

Purpose: The reverse path currently DROPS embedded optical images (the v0.5 MAJOR-8 degrade). This
primitive is the read-out half that restores forward↔reverse symmetry. It must be bounded-memory
(a real `.svs` is large) and must apply the export-filename path guard so an archive-supplied
`source_name` can never write outside the output directory.

Output: `export_image_members(...)` returning, per image, the exported external filename (relative
to the `.imzML`) for Plan 02 to thread into the `IMS:1006008` location, plus the descriptive
`ImageEntry` carried alongside; a missing/unreadable member is skipped (logged), never fatal.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Tampering | export filename from `source_name` | mitigate | `sanitize_export_name` rejects `/`, `\\`, `.`, `..`, multi-component paths BEFORE building any write path (mirrors forward guard src/write/convert.rs:515-536); rejected ⇒ skip, never write |
| T-21-02 | Denial of Service | large `.svs` member read | mitigate | bounded `std::io::copy` streaming (fixed buffer); never `read_to_end` the whole member into RAM |
