# Requirements Archive: mzML2mzPeak — Milestone v0.8

**Milestone:** v0.8 — Sample-metadata ingestion (SDRF + ISA), channels-as-labeled-samples, reporter-quant,
byte-for-byte roundtrip validation
**Shipped:** 2026-06-09 · **Tag:** `v0.8`
**Defined:** 2026-06-09 · **Closed:** 2026-06-09 (22/28 active requirements DONE; 6 open = carried to v0.9 or deferred ≥v0.9)

**Core Value:** Convert an arbitrary imzML imaging dataset into a valid imaging mzPeak file without losing
spatial or spectral information — every pixel's coordinates and its m/z + intensity survive the roundtrip.

> v0.8 delivered the full sample-metadata ingestion pipeline: a unified `StudyMetadata`/`SourceCurie` model
> fed by a pure-Rust SDRF reader (`csv`) and a pure-Rust ISA-Tab/JSON reader; verbatim embed as the
> lossless anchor; lean `sample_list` projection + `metadata.study` global context; isobaric channels as
> labeled `sample_list` entries (`MS:1002602`, RATIFIED-E — no `channel_list`); optional reporter-ion quant
> (`--reporter-quant`); and a byte-for-byte roundtrip validation hard gate (VAL-01). The upstreaming and
> de-vendoring work (Phases 22, 29) and the upstream list-valued `ms_run.sample_ref` PR (Phase 30b) are
> carried to v0.9 as owner-gated / externally-gated non-blocking work. Phase 36 / SM-07 / SCOPE are
> deferred ≥v0.9 (verbatim blob holds fidelity). v0.8 added one new dependency: `csv = "=1.3.1"`.

---

## Ratified cornerstones (owner, 2026-06-09 — do NOT re-decide)

| # | Cornerstone | Decision |
|---|---|---|
| **A** | CV / OBO depth | Passthrough + structure-only. Own verbatim-string `SourceCurie`; cvParam when accession present, else userParam; shape-only validation; zero new ontology deps. |
| **B** | Reader implementation | Pure-Rust readers + optional external oracle. `csv` (SDRF) + hand Tab parser + `serde_json` (ISA). `--validate-sample-metadata` shells to `sdrf-pipelines`/`isa-api` only when present — non-blocking, **never required at runtime**. |
| **C** | Upstream / binding | Upstream-first. Block native run-binding on `ms_run.sample_ref` merge into HUPO-PSI/mzPeak; no local writer fork. Binding = run-level; per-spectrum `assay_ref` deferred ≥v0.9. |
| **D** | Milestone shape | One milestone — SDRF + ISA together. |
| **E** *(JK)* | Channel model | Samples-as-channels. Each isobaric channel = a `sample_list` entry with `MS:1002602` cvParam. **NO `channel_list` / `plex_id` / `channel_set`**. |
| **F** *(JK)* | Run binding | `ms_run.sample_ref` is LIST-valued (multiplexing falls out of the list). |
| **G** *(JK)* | Posture | Lean. Verbatim blob = anchor; `factor_values`, `comment[]` scope decomposition, full `characteristics→Param` shaping deferred ≥v0.9. |
