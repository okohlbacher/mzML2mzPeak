<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| in-memory record (dtype/coords/ArrayRef) → emitted .imzML bytes | Values formatted into XML text/attributes cross into a file a strict parser will re-read |
| ImagingMetadata (serde Value, may be absent) → <scanSettings> | Optional, possibly-missing geometry must never become fabricated output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-INJ | Tampering | every dynamic text/attribute value in imzml_writer.rs | mitigate | Route EVERY dynamic value through quick_xml::escape::escape before write (asserted by escaping_roundtrips + grep gate). |
| T-09-ENC | Tampering/Repudiation | XML prolog vs on-disk bytes | mitigate | Declare encoding="UTF-8" and write Rust String (UTF-8 by construction); declares_utf8 test asserts prolog + valid-UTF-8 bytes. The v0.3 Latin-1 landmine class. |
| T-09-DTYPE | Tampering | dtype_cv mapping / per-array dtype term | mitigate | dtype driven by NumArray::source_dtype(); non-{f32,f64} rejected via ReverseError::UnsupportedDtype (never cast); no as_f64 in module (grep gate). Wrong dtype → wrong read-back width. |
| T-09-FAB | Integrity | <scanSettings> when metadata.imaging absent | mitigate | Emit empty scanSettingsList count="0"; fabricate no grid dims (scansettings_absent_degrades test). |
| T-09-MEM | DoS | 34,840-spectrum emission | mitigate | Stream one <spectrum> per write_spectrum into BufWriter; never accumulate (RCLI-02 carry-forward). |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | No packages added — quick-xml/mzdata/thiserror/serde_json already pinned (09-RESEARCH Package Legitimacy Audit: all Approved, no change). git diff --quiet Cargo.toml Cargo.lock enforced. |
</threat_model>
