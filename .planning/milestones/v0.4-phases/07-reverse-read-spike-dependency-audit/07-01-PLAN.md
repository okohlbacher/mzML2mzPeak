proof (Plan 02) builds on. This is the interface-first foundation: define `ReverseError`

`src/lib.rs` wiring, and `tests/fixtures/reverse/mod.rs` fixture builders.

create `src/reverse/`. We deviate minimally and seed `src/reverse/` with ONLY the error

requires `ReverseError` to be importable by integration tests, and bin targets are not
importable. The read LOGIC stays in the throwaway spike (Plan 02); Phase 8 promotes that
logic into `src/reverse/source.rs` — it does not rewrite this enum.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | non-imaging / wrong-CV archive later treated as imaging | mitigate | `ReverseError::NotImaging` variant defined here (fail-closed contract); enforced in Plan 02's read path. |
| T-07-02 | Tampering | array dtype outside {Float32,Float64} silently cast | mitigate | `ReverseError::UnsupportedDtype` variant carries the offending `BinaryDataArrayType`; rejects rather than coerces (Security V5). |
| T-07-03 | Denial of Service | malformed archive -> panic via unwrap on a fallible read | mitigate | Every fallible read maps to a typed `ReverseError` arm (no `unwrap`); contract designed so Plan 02 surfaces `Option`/`io::Result` as errors. |
