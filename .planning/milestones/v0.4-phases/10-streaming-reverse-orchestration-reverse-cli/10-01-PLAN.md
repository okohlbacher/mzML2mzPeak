<objective>
Build the library half of the reverse pipeline: split `ImzmlWriter` into independently callable
header/body/trailer phases (additive, keeping the Phase-9 eager-header lifecycle as a wrapper),
promote `read_pixel`/`decode_axis` from the `src/bin` spike into `src/reverse/source.rs`, and
write `src/reverse/convert.rs` — the bounded-memory Option-C orchestrator that threads Phase 7
read → Phase 8 `.ibd` append → Phase 9 `<spectrum>` emit into one streaming loop with correct
checksum ordering.

Purpose: This is the convergence point of Phases 7-9 and the source of RCLI-02 (bounded-memory
streaming). The genuinely-new design here is the Option-C body-temp-file dance that lets the
`<fileContent>` MD5 (only known after the last `.ibd` append) sit in the header (structurally
first in the document) without buffering the whole XML in memory.
Output: `src/reverse/{source.rs, convert.rs}` (new), `src/reverse/imzml_writer.rs` (additive
split), `src/reverse/mod.rs` (2-line wiring). No new crates.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-supplied `.mzpeak` → reverse reader | the input archive is untrusted/possibly-malformed; every read must surface a typed error, never panic |
| reverse writers → filesystem (`.imzML`, `.ibd`, temp body) | output files written from decoded input; partials must not be left on failure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-NIMG | Information Disclosure / correctness | non-imaging input | mitigate | Pre-check `read_pixel(reader, 0)` → `NotImaging` BEFORE creating any output file (Task 3); no garbage `.imzML`/`.ibd` produced for a non-imaging archive |
| T-10-PART | Tampering (integrity) | partial output on mid-stream failure | mitigate | Best-effort `remove_file` of `.ibd`/`.imzML`/temp body on any `Err` (Task 3, Pitfall 4); IbdWriter poisons but cleanup is orchestrator-owned |
| T-10-MEM | Denial of Service | 34,840-pixel input | mitigate | One `ReversePixel` live per iteration, no `collect`, `std::io::copy` fixed-buffer body concat; `load_all_spectrum_metadata()` once to avoid O(n^2) (Task 3, RCLI-02) |
