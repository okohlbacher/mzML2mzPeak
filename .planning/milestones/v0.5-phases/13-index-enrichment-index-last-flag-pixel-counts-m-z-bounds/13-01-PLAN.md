<objective>
Enrich the forward `imzML → imaging mzPeak` output's `metadata.imaging` index block — written LAST via
the existing terminal seam — with the imaging flag, per-dimension pixel counts (declared grid counts
when the imzML provides them, else derived from the max observed coordinate), and global MS1 m/z bounds,
computed by two bounded-memory streaming accumulators. Delivers IDX-01, IDX-02, IDX-03.

Purpose: the index block is the discovery surface readers branch on; it must report the real pixel
extent and the true MS1 m/z span without buffering the whole dataset.
Output: an `IndexAccumulator` in `src/write/writer.rs`, wiring in `src/write/convert.rs`, and
emit→read-back integration tests in `tests/write_roundtrip.rs`.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Tampering/Information disclosure | IndexAccumulator MS1 m/z min/max | mitigate | NaN-guard each f64 with `is_finite()` before updating min/max so a malformed/non-finite m/z value cannot poison the emitted mz_range (a NaN would otherwise propagate and produce a bogus or non-comparable bound). |
| T-13-02 | Denial of service | IndexAccumulator over the full pass | mitigate | Accumulator holds only scalar running state (coord maxima + two Option<f64>); it never buffers per-spectrum vectors, so a large dataset cannot exhaust memory (IDX-01 bounded-memory contract; convert() stays one-spectrum-at-a-time). |
| T-13-03 | Tampering | observed-max coordinate derivation | accept | Coordinates are already validated as positive 1-based indices upstream in to_mzdata (WriteError::NonPositiveCoordinate); the accumulator never fabricates counts beyond the observed max (IDX-02 "never fabricate beyond observed"). i64 coordinate overflow on max is not realistic for MSI pixel grids — accepted. |
| T-13-SC | Tampering | npm/pip/cargo installs | mitigate | No new crates this phase (CLAUDE.md constraint); uses only existing `log`, `serde`, and Phase-12 schema types. No package install tasks → legitimacy gate not triggered. |
