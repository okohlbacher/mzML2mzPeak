## Goal

Given an mzML plus a sibling **SDRF-Proteomics TSV** or an **ISA bundle** (ISA-Tab `i_/s_/a_` triple or
ISA-JSON), pull the global/study metadata and the sample rows applicable to that mzML into the mzPeak
archive — **losslessly** (verbatim blob anchor) and **queryably** (minimal scoped projections with stable
join keys) — so the binding survives the roundtrip and validates against the source ecosystem's reference
tools. The keystone is a format-agnostic unified `StudyMetadata` / `SourceCurie` model that both readers
populate and a single emitter consumes. Channels are reframed as labeled `sample_list` entries
(`MS:1002602`), the `channel_list` construct is dropped. An optional `--reporter-quant` path stores
reporter-ion intensities as an `auxiliary` array. Byte-for-byte roundtrip validation (internal Rust) is the
hard gate; an optional non-blocking external oracle (`--validate-sample-metadata`) is the bonus.

Two work streams: (1) **SDRF + ISA sample-metadata ingestion** (Phases 30, 30b, 31–37); (2) the
**upstreaming / de-vendoring finish** relocated from v0.7 (Phases 22, 29). The three carried-forward
phases (22 / 29 / 30b) are owner-gated or externally-gated non-blocking external work. Every buildable
phase shipped with 565 tests green.

## Key outcomes

- **565 tests green** (lib + integration; PXD001283 acceptance `#[ignore]`-gated unchanged). Build clean;
  forward SDRF + ISA embed + reverse extract + `--reporter-quant` + `--validate-sample-metadata` PASS;
  mzPeakValidator validates the output.
- **Unified `StudyMetadata` / `SourceCurie` model** — format-agnostic keystone that both the SDRF reader
  (`csv`, tab/flexible/quoting(false)) and the ISA readers (pure-Rust ISA-Tab block parser + ISA-JSON
  serde/@id resolution) populate; a single `project_sample_list` emitter consumes both. No Python
  dependency; no OBO bundle; CV = passthrough + structure-only (Cornerstone A).
- **Verbatim blob anchor (lossless)** — the SDRF or ISA bundle is embedded byte-for-byte as a typed ZIP
  member (`entity_type: sample-metadata`, `data_kind: sdrf|isa`) before any projection. A
  `metadata.sample_metadata` back-ref records accession, source URI, sha256, and precedence
  (`repo_wins`). `extract_sample_metadata_member()` + `--reconstruct-sdrf`/`--reconstruct-isa` reverse
  the embed; the hard VAL-01 gate proves byte-for-byte identity on label-free + TMT fixtures.
- **Samples-as-channels (no `channel_list`)** — each isobaric channel is a `sample_list` entry with a
  `sample label` cvParam (`MS:1002602` + reagent child, e.g. TMT126), `reporter_mz`, `channel_role`, and
  `tag_modification` (Unimod) params. Static reagent table covers TMT 126–131 (+N/+C) and iTRAQ 113–121
  with PSI-MS CV accessions. No `channel_list` / `plex_id` / `channel_set` construct (RATIFIED-E).
- **Reporter-ion quantitation** — `--reporter-quant` stores per-MS2 reporter intensities as one
  `auxiliary` `NonStandardDataArray` per spectrum, channel-ordered, with a `channel_id` param;
  own-reader read-back spike CONFIRMED. Byte-identical when the flag is absent.
- **Byte-for-byte roundtrip validation (VAL-01)** — label-free SDRF (PXD020187) PASSED; TMT-10plex SDRF
  (PXD011799 fr8.mzML, 290 MB) PASSED; ISA-Tab (MTBLS5358) skip-guarded (no spectral mzML present, not
  a silent pass). Internal Rust assertion — `extract_sample_metadata_member()` reads back the verbatim
  ZIP member; never regenerates from projections.
- **Non-blocking external oracle (VAL-02)** — `--validate-sample-metadata` shells to `sdrf-pipelines` /
  `isa-api` only when present; always returns `Ok(ValidationOutcome)` (spawn failure → `Skipped`);
  Python stays out of the hard conversion path.
- **Upstream batch bundle PREPARED AND HELD** — `docs/upstream/v0.8-spec-batch-bundle.md` (proposals
  P-02..P-09: verbatim embed, `sample_list`, samples-as-channels, reporter-quant, `metadata.study`) +
  `docs/upstream/ms-run-sample-ref-writer-pr.md` (list-valued `ms_run.sample_ref` writer PR) assembled
